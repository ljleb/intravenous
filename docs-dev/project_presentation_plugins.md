# Project presentation plugins

A presentation supplies the contents of a lane. The host owns playback,
input devices, layout, observation subscriptions, and project edits. Project
packages publish built WebAssembly artifacts alongside their definitions.

Start with the [authoring APIs](api/README.md) for the tutorials, explanations,
how-to guides, and technical references. The [C ABI](api/reference/presentation_c_abi.md)
specifies the wasm32 boundary. The [C++ SDK](api/reference/presentation_cpp.md)
describes class registration and authoring helpers.
