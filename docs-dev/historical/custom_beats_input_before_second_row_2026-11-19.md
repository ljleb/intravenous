# Custom beats input before the second row

Preserved on 2026-11-19 from `docs-dev/project_playback_and_presentation_grids_direction.md`.
See the [current ruler layout](../project_playback_and_presentation_grids_direction.md#timeline-nodes-and-project-snapping).

> **Custom** uses the editor-managed `builtin.timeline`. Its `beats`
> input occupies the seconds readout in the ruler's left column. Compatible
> BeatEvent outputs can connect to it using ordinary graph cables. Multiple
> sources contribute to the same grid.

The layout accepted on 2026-11-19 then placed the Custom `beats` input
below the playback indicator, seconds, and sample count in a full-height
port row. On 2026-11-24 the owner kept that row for narrow headers and
taller lanes, and allowed mini and nano layouts to share the clock row
when both controls fit. See the [responsive ruler layout](../project_playback_and_presentation_grids_direction.md#timeline-nodes-and-project-snapping).
