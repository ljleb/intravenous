# Middle-drag zoom before continuous wrapping

Preserved from the working copy of `docs-dev/node_presentation_and_manual_controls_direction.md`
on 2026-11-18. The owner changed the zoom anchor to follow accumulated mouse
travel across viewport edges.
[Current viewport bindings](../node_presentation_and_manual_controls_direction.md)

> During either modified middle drag, the displayed cursor wraps at the graph
> viewport edges. Zoom uses the actual mouse travel across each wrap. The wrapped
> cursor supplies the anchor for the selected zoom axis.
