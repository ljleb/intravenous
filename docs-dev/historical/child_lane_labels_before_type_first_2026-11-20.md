# Earlier Child Lane Labels

On 2026-11-20, the owner requested type names as the primary labels for
virtual and concrete lanes. The current rules appear in
[Module Interoperability And Graph Macros](../module_interoperability_and_graph_macros_direction.md).

> Each virtual node has a lane named for its C++ declaration. Expanding it
> shows its concrete members, labeled with the declaration name and a
> one-based member index.
>
> The lane uses the C++ declaration name and adds the type when
> needed to distinguish rows.
