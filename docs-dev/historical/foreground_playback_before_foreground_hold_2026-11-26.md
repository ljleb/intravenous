# Foreground playback before Shift+Space

_Historical record of the transport table and pause contract in
[Project Playback And Presentation Grids](../project_playback_and_presentation_grids_direction.md#transport-and-one-continuous-foreground-execution-history),
2026-11-26._

Before there was a separate foreground hold, every pause was a project
playback pause. A paused seek changed the background destination without
relocating the foreground playhead. Tick kept executing and advancing for
microphone input, live instruments, delays, and reverbs. Starting playback
realigned the foreground to the held project position.
