# Module expansion before the header footer

This text records the double-click rule from the module presentation design.
The owner changed the expansion gesture on 2026-11-21 because the double-click
was unreliable. See the [current module header design](../module_interoperability_and_graph_macros_direction.md#module-ports-and-child-lanes).

> Double-click the module header to expand or collapse its children. Use Alt plus
> double-click on an editable module name to rename it. A source link opens the
> source on click.
