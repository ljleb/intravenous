# Custom bar labels before Region-relative numbering

This rule came from the Custom ruler section of the timeline design. On
2026-11-22, Region-relative numbering replaced the sample-zero rule so that
Regions can start anywhere. See the
[current timeline design](../project_playback_and_presentation_grids_direction.md#timeline-nodes-and-project-snapping).

> The Custom ruler requests runs for bar labels. In a depth-zero Region that
> starts at sample zero, the first bar is 1. In a Region that ends at zero, the
> last bar is 0. Other Regions still supply grid lines and snap targets.
