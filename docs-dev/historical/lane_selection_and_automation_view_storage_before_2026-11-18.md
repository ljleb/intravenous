# Earlier lane selection and automation view storage

Historical. Preserved on 2026-11-18 after the owner chose range selection and
one project file for graph layout.

## Lane selection

From the [lane interaction direction](../node_presentation_and_manual_controls_direction.md#navigation-selection-and-lane-order).

> Interacting with a lane selects it. Ctrl-click toggles it, and Shift-click
> adds it. A small indicator at the header/content boundary marks selection.
> The previous selection rules are [preserved here](./vue_lane_and_point_selection_before_2026-11-18.md).

## Automation view storage

From the [value display and panning direction](../vue_presentation_refinement_direction.md#value-display-and-panning-2026-11-18).

> VS Code saves the display mode, value ruler, pan, and zoom for each curve in
> the project folder setting `intravenous.automationCurveViews`.
