# Module footer before the inset line

This text records the original visual treatment from the module presentation
design on 2026-11-21. The inset line replaced the gradient to fit the editor theme.
See the [current module header design](../module_interoperability_and_graph_macros_direction.md#module-ports-and-child-lanes).

> A faint gradient appears when the pointer enters the header. The gradient
> brightens and the cursor changes to a hand over the footer.

## Inset line

The module presentation design specified this treatment before the gradient
returned on 2026-11-22.

> A thin line in the editor theme's foreground color appears when the pointer
> enters the header. The line brightens and the cursor changes to a hand over
> the footer.
