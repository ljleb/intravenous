# Concrete Member Input Knob Defaults

On 2026-11-20, the owner asked that concrete member input knobs use
the defaults declared by their ports. This supersedes the blanket rule in
[Node Presentation And Manual Controls](../node_presentation_and_manual_controls_direction.md#persistent-manual-controls).

> The same knob components serve the ports of C++-constructed nodes. Eligible
> virtual and concrete member input knobs start disabled.
>
> An enabled concrete member input takes precedence at its port.
