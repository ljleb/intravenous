# Node creation before the tag picker

Archived on 2026-11-19 from `docs-dev/node_presentation_and_manual_controls_direction.md`
and `docs-dev/vue_client_implementation_stages.md`. The tag picker replaces the old
creation form and settles the search interface. See
[Node creation and names](../node_presentation_and_manual_controls_direction.md#node-creation-and-names).

> Creation must offer a convenient way to find definitions without knowing their
> IDs. Search by display name or ID, tag search, and visual browsing are candidate
> interfaces. The owner has not selected one of these interfaces yet.

> Shift+A opens the existing Add Node form. The new lane goes after the lowest
> selected lane, or at the bottom without a selection.
