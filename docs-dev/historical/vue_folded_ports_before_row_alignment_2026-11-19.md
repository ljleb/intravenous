# Folded ports anchored to the header bottom

This records the earlier popover placement from the Vue presentation refinement
direction on 2026-11-19. [The current folded-port layout](../vue_presentation_refinement_direction.md#folded-inputs-extend-the-existing-lane-header)
supersedes its placement rule.

Hover anywhere in the lane header to open one popover immediately below its
bottom edge. The popover continues both columns, with each column's hidden
rows in definition order and aligned with their controls above. Each revealed
port uses its own socket for cable endpoints. Scroll the additional rows when
they exceed the available viewport height. Keep the continuation open while
the pointer crosses between it and the header or while a knob is in use.
During a cable drag, reveal the compatible destination column. Shift retains
the separate per-port connection chooser.
