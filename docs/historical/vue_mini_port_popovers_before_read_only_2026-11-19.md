# Port popovers at mini and nano heights

This records the earlier compact-height behavior from the Vue presentation
refinement direction on 2026-11-19. The owner superseded it with
[read-only port symbols](../vue_presentation_refinement_direction.md#folded-inputs-extend-the-existing-lane-header).

At mini and smaller heights, use a single port symbol or a stack on each side.
The shared popover opens below the header with full-size controls and wraps
long names.
