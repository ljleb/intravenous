# Middle-button zoom before the live horizontal anchor

This note preserves the earlier rule from the working copy of
`docs/node_presentation_and_manual_controls_direction.md` on 2026-11-18.
The owner requested that horizontal zoom follow the cursor's current
horizontal position. See the [current gestures](../node_presentation_and_manual_controls_direction.md#lanes-and-reusable-timeline-display).

> For a middle-button zoom, the press sets the anchor and selects the zoom axis.
