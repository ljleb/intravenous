# Pre-big-rename documentation snapshots

These files preserve the complete pre-cleanup versions of current design documents
that were edited during the September 2026 terminology and dead-code cleanup.
They are historical, non-normative records retained so design rationale, constraints,
and implementation history are not lost when the current documents are corrected.

The snapshots preserve the complete pre-cleanup text; trailing EOF whitespace may be
normalized. Relative links inside them reflect the files' original locations under
`docs/` and may no longer resolve from this directory.
Use the corresponding current document in `docs/` for normative architecture.
