# Middle-button zoom before the live vertical anchor

This note preserves the Alt gesture from the working copy of
`docs/node_presentation_and_manual_controls_direction.md` on 2026-11-18.
The owner rotated the Ctrl gesture for use with Alt. See the
[current gestures](../node_presentation_and_manual_controls_direction.md#lanes-and-reusable-timeline-display).

> Alt + middle-button drag uses vertical mouse movement for vertical zoom, with
> the same effect as Alt + wheel.

The viewport interaction notes anchored vertical zoom at the press position.
