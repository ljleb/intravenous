# Lane knobs before default inline display

Historical context, preserved 2026-11-14 from the working-tree version of
`docs/node_presentation_and_manual_controls_direction.md`. The owner requested
that knobs remain visible beside inputs which fit directly on the lane.
This replaces the earlier requirement to expose those knobs through popovers.
The current contract is in
[Node Presentation and Manual Controls](../node_presentation_and_manual_controls_direction.md).

## Superseded contract

The default presentation places one radial knob beside each eligible input in
its port popover, or once in that input's connection popover. A single eligible
input can open a port popover too. Keep the lane's wiring interface compact and
avoid a second list of input identities in its content area.
