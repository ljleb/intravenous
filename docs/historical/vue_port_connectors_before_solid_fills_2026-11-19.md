# Port connectors before solid fills

_Historical. Preserved on 2026-11-19 when the owner chose filled connectors
whose color shows connection state._

From [Node Presentation And Manual Controls](../node_presentation_and_manual_controls_direction.md#knobs-and-port-handles),
which now describes the replacement.

> A port popover containing exactly one port uses a single-circle icon. The
> circle is empty when disconnected and filled when connected. Hover still opens
> the popover. This changes the icon, not the popover interaction.

The previous [unavailable-port feedback](../node_presentation_and_manual_controls_direction.md#proposed-port-area-and-temporary-expansion)
also specified that filled and dashed connection states remain visible when
the port color is muted.
